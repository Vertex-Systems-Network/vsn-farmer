# Banks

**Options Bank** = for each decision point, every researched option with a score → we pick, then record ADR.
**Systems Bank** = existing products/systems studied in depth → what to copy, what to beat.

## Scoring rubric (1–5 each, write the number + one-line reason)
| Criterion | Meaning |
|---|---|
| Impact | Value for the farmer / business |
| PK fit | Works in Pakistan: language, payments, availability, low bandwidth |
| Cost | 5 = cheapest at our scale |
| Effort | 5 = easiest to build/integrate |
| Risk | 5 = lowest lock-in / reliability / legal risk |

Status values: `open` · `shortlisted` · `chosen` · `rejected` · `needs-verification`.
New entry → copy from `_templates/`. Always add sources (links + date checked).
"Better than" ideas: every systems entry ends with **Improve on it** — these feed `tasks/BACKLOG.md`.
